Notch Activity Study

When an agent is actually working, its mark in the strip animates. Three ways of fitting that into the compact strip, and five animations, all at one point per pixel against a real 220×38 notch.

The detection is settled. tokscale clients --json returns a sessionsPath per client — ~/.claude/projects, ~/.codex/sessions, and so on for every tool it knows. An agent appends to its session file as it works, so a file touched in the last few seconds is that agent working. Watched with FSEvents, it costs no polling, and it needs no list of agents in our code: a tool tokscale learns about later lights up on its own.

The nine, at three sizes

Eleven pixels cannot be judged at eleven pixels. Every animation runs at 1× on the strip’s own black beside 4× and 8× — but the 1× column is the one that decides, and several of these are legible only in the other two.

Considered, ruled out

Both were good ideas. Both are on the page with their reason attached, because a design record that only lists what survived is a record of nothing.

Constraints this is built under

Hard

Nothing may change size

The strip is measured by SwiftUI and the panel window is sized to the result. An animation that grew by one pixel would resize a window sixty times a second and drag the hole off the camera cutout with it.

So each animation is a strip of frames inside a box of fixed size, stepped with transform alone. Variant B reserves its slot while idle for the same reason.

Honest

What mtime can and cannot say

A file touched a second ago means the agent wrote a second ago. A long think with no output looks the same as idle — and the first build got the size of that wrong. Measured on a live session, the gap between writes while thinking was 26 seconds.

Process CPU was the obvious way out and does not work: an idle claude burns about 10 ms a second keeping its interface alive, a working one about 21. Two times is not a threshold.

So the state decays rather than blinking off: lively for twelve seconds after a write, settling — slower, dimmer, but still moving — out to fifty. An eight-second window went dark mid-task, and with each agent lit only briefly after each of its own writes, two agents working together never overlapped and read as taking turns.

Cheap

It runs all day

This is the state the app is in for most of its life, so the animation has to cost close to nothing: a stepped sprite at four to eight frames a second, not a per-frame redraw.

And it stops entirely under Reduce Motion. Nothing here is the only way to learn anything — the figure beside it says the same thing.

The animation is drawn in the working agent’s own brand colour and in no other, which is the same rule the rest of the app runs on — and it is what lets eleven pixels answer “who is working” rather than only “something is”. Red stays reserved for a spent quota.
